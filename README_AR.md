# DZ SHOP 15

مشروع Flutter أولي لمتجر جزائري بتصميم أسود وذهبي.

## تشغيله
1. افتح المجلد في Android Studio أو VS Code بعد تثبيت Flutter.
2. نفّذ `flutter pub get`.
3. نفّذ `flutter run`.

## بناء APK عبر GitHub
ارفع ملفات المشروع إلى المستودع، ثم افتح Actions. سيُبنى التطبيق تلقائياً عند push إلى main أو يدوياً عبر Run workflow. حمّل Artifact باسم `dz-shop-15-apk`.

## تنبيه مهم
هذه واجهة تجريبية بمنتجات وأسعار رمزية وسلة محلية فقط. لا توجد قاعدة بيانات أو تسجيل برقم الهاتف أو طلبات حقيقية أو SMS أو إشعارات أو ربط Yalidine حتى الآن. يلزم إعداد خادم وقاعدة بيانات وخدمات خارجية قبل الاستخدام التجاري أو النشر.
